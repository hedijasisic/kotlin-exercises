# Kotlin Exercises

A collection of my Kotlin exercises and solutions, done as part of the course **Mobile Application and Services Development**.

Author: **Hedija Šišić**

New exercises are added to this repository as the course progresses.

---

## Repository structure

Each exercise has its own folder, named `exercise-N` (for example `exercise-1`, `exercise-2`, ...). A folder contains:

- the exercise description (PDF or other document), and
- the solutions as one or more Kotlin (`.kt`) files.

Each folder is self-contained, so to see what an exercise covers, open its folder.

---

## How to run the code

**Option 1: Kotlin Playground (no installation)**
1. Open [play.kotlinlang.org](https://play.kotlinlang.org).
2. Copy the contents of a `.kt` file into the editor.
3. Click the **Run** button.

**Option 2: IntelliJ IDEA**
1. Open the `.kt` file in IntelliJ IDEA.
2. Click the green arrow next to `fun main()`.

Within a file, each task is usually written as a separate function, and `main()` calls them in order.
